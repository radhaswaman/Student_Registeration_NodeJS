# Student Registration System

A simple Node.js and SQLite project where students can submit their details and view the registered list.

## Features

- Add student details through a web form
- Store records in a SQLite database
- View all registered students in a table

## Run It

```bash
npm install
npm start
```

Open `http://localhost:3000` in your browser.

## Setup on a New Device

1. Install Node.js from https://nodejs.org if it is not already installed.
2. Copy or clone this project folder to the new device.
3. Open a terminal inside the project folder.
4. Run `npm install` to install the dependencies.
5. Run `npm start` to start the app.
6. Open `http://localhost:3000` in the browser.

The SQLite database file is created automatically the first time the app runs.
